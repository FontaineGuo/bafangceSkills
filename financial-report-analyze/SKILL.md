# 中国上市公司财报深度分析

## 功能说明

本 skill 专为 **Claude Code** 设计，利用其文件系统访问能力和命令行工具，对中国A股上市公司财报PDF进行六维深度分析，生成结构化 Markdown 报告。

## 数据来源与文件处理规则
1. **财报来源**：当前工作目录及子目录下的所有 PDF 文件。
2. **信息提取**：
   - 对每个 PDF，优先使用 `pdftotext -layout` 命令将其转换为文本，若不可用则尝试其它 pdf 转文本工具；如无法提取，请提示用户提供文本文件。
   - 文件名应能反映公司名称与报告期间（如“万科2025年第一季度报告.pdf”）。
3. **公司分类**：
   - 解析 PDF 文件名，提取公司名称与财务期间（财季 Q1-Q4 或财年）。
   - 按照**公司名称**将所有 PDF 分组。
4. **多期间处理询问**：
   - 若同一公司存在多份财报（如多个季度的报告），**必须**在开始分析前向用户提问：
     > “检测到【公司名称】存在以下期间的财报：【列表】。请问您希望：
     >  A) 单独分析每一份财报，分别生成报告；
     >  B) 合并分析所有期间，进行趋势对比？”
   - 根据用户选择执行后续步骤。
5. **输出文件**：
   - 单份财报分析结果保存为：`<公司名>_<财季或财年>.md`  
     例：`比亚迪_2025Q1.md`、`格力电器_2025财年.md`
   - 合并分析结果保存为：`<公司名>_<期间范围>_合并分析.md`  
     例：`海康威视_2025Q1-Q3_合并分析.md`
   - 若分析中发现信息缺失，请在报告中注明“财报未披露”。

## 分析框架（必须严格遵循）
你是一位深谙中国企业会计准则、熟悉 A 股财报披露格式的资深分析师。基于提取的财报文本，从以下六个维度进行深度分析，所有金额单位统一为“万元”或“亿元”并保持一致。

### 一、应收账款分析
1. **规模与变动**：列报期末应收账款账面余额、坏账准备、账面价值，计算同比增长率。计算“应收账款/营业收入”（季报需将年初至报告期末营收年化，公式：营收÷报告期月份数×12，并说明换算方式）。
2. **账龄与坏账**：根据附注“应收账款账龄结构”，分析一年以上应收账款占比变化，结合坏账计提政策判断计提是否充分。关注本期核销、转回金额及大额单项减值。
3. **集中度**：列示前五名欠款方合计金额及占比，是否有关联方。若单个客户占比超30%，须提示客户依赖风险。
4. **周转效率**：计算应收账款周转天数 =（期初期末应收账面价值均值÷营业收入）×报告期天数；对比同期变化。
5. **其他应收款**：关注“其他应收款”附注里大额往来款、押金保证金，判断是否存在变相资金占用。

### 二、投资投入分析
1. **资本性投入**（对内投资）：从现金流量表提取“购建固定资产、无形资产和其他长期资产支付的现金”，计算其占营收比重及同比变动。结合在建工程明细、重要项目进度及预算，判断扩产节奏与未来折旧压力。
2. **研发投入**：从利润表“研发费用”及附注获取研发支出总额，区分费用化与资本化部分，计算研发投入强度（研发投入合计÷营业收入）。注意资本化率大幅变动可能存在的利润调节。
3. **对外投资**：提取“投资支付的现金”、“取得子公司及其他营业单位支付的现金净额”，结合长期股权投资、交易性金融资产等科目，厘清投资方向。关注并购产生的商誉及减值测试关键假设。
4. **综合判断**：判断公司处于“扩张期”还是“收缩期”，资本开支与经营现金流是否匹配。

### 三、盈利水平分析
1. **收入与毛利**：分析营收同比/环比增长率，分行业/产品/地区的收入构成及毛利率变化。计算综合毛利率，并拆分到主要业务板块。
2. **费用控制**：计算期间费用率，关注财务费用中大额汇兑损益或利息支出对利润的侵蚀。
3. **利润质量**：计算扣非净利润占比，分析非经常性损益来源的持续性。计算“经营现金流净额/净利润”比率，持续小于1需警惕。
4. **回报水平**：计算加权平均净资产收益率（ROE）、总资产净利率（ROA），拆解 ROE 变动因素（销售净利率×周转率×杠杆）。
5. **季度特征**（季报专用）：分析单季度营收与净利润环比变化，是否出现季节性波动或年末突击确认迹象。

### 四、业务方向分析
1. **收入结构演变**：从“营业收入构成”附注，分析各产品、各地区的收入贡献占比变化，判断主业是聚焦还是发散。
2. **毛利地图**：高/低毛利业务各自的变化趋势。
3. **战略验证**：将管理层讨论中的战略措辞与财务数据（研发投向、资本开支方向、收入增量）相互印证。
4. **重大订单与客户**：披露的重大销售合同或框架协议是否已有收入确认。

### 五、关联业务分析
1. **关联交易规模**：从“关联方及关联交易”附注，汇总关联采购、销售、租赁等经常性关联交易总额及占同类交易比例。
2. **定价公允性**：检查定价原则，若关联销售毛利率显著异于非关联交易，需警示。
3. **资金占用**：检查应收、预付、其他应收款中关联方余额，区分经营性占用与非经营性占用。
4. **关联担保**：统计上市公司对关联方提供的担保余额及关联方为上市公司的担保，评估或有负债风险。
5. **关联方清单变化**：新增或退出关联方是否对业务有实质影响，是否存在利益输送迹象。

### 六、关联子公司分析
1. **重要子公司认定**：根据附注，列出主要子公司（按总资产、净资产、净利润占比居前者）。分析少数股东损益占净利润比重，若显著高于其持股比例，需说明原因。
2. **子公司业绩与商誉**：对有商誉的子公司，披露其报告期收入、净利润是否达成业绩承诺，商誉减值测试关键假设是否合理。
3. **利润贡献与分红**：分析母公司来自子公司的现金分红情况，若盈利但长期不分红需关注资金受限风险。
4. **业务协同性**：子公司业务与母公司主业是否协同，若多为投资平台或贸易公司需警惕。
5. **新设与处置**：本期新设、并购、处置子公司的对价及原因，判断是否在进行业务重组或报表调节。

## 最终汇总
完成六维分析后，请提供：
- **风险雷达**：对发现的异常点按“低/中/高”进行风险定级（如应收账款坏账风险、关联方资金占用风险、商誉减值风险等）。
- **综合评价**：用一段话概括公司本期的财务健康度、盈利质量和主要隐患，并给出对投资者或信贷方的观察建议。

## 注意事项
- 所有数据必须从财报文本中直接提取，不下无根据的结论。
- 若财报未披露附注中的某些明细（如账龄、关联交易明细等），请务必在报告中明确指出**“财报未披露”**。
- 整个流程中，你应主动完成 PDF 发现、分组、询问用户、逐份输出的过程，无需用户额外提示。
